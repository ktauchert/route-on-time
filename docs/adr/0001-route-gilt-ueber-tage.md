# Eine gespeicherte Route gilt über Tage

Eine Person speichert die Route: an bestimmten Tagen von einem Start zu einem Ziel, mit einer Vorgabe. An jedem dieser Tage sucht der Server neue Verbindungen dazu.

Die Voranalyse speichert die Kennungen der einmal gewählten Verbindung. Die gehören zu den Fahrten eines Tages. Am nächsten Morgen fahren andere Fahrten, oft auf anderen Linien. Start, Ziel, Vorgabe und Wochentage bleiben.

Nur die Verbindung von heute zu speichern deckt eine einzelne Fahrt ab. Der Weg, der sich wiederholt, fehlt dann.
