# Eine Route hat eine Richtung

Eine Route führt von einem Start zu einem Ziel. Der Rückweg ist eine zweite Route, mit eigener Vorgabe und eigenen Wochentagen.

Eine Route mit beiden Richtungen wäre beim Pendeln ein Formular weniger. Sie würde zwei Vorgaben, zwei Uhrzeiten und zwei Stände in einem Datensatz vermischen. Zwei Routen lassen sich einzeln prüfen und einzeln löschen.
